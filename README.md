# Good News Christian A Cappella

This flat version is designed for GitHub's browser upload.

1. Extract the ZIP.
2. Open the extracted good-news-github-pages folder.
3. Select all the files inside (Ctrl+A) and drag them together onto GitHub's Add file > Upload files page. The photos must be uploaded alongside index.html, not in a subfolder.
4. Commit changes. In Settings > Pages select Deploy from a branch, main, /(root).

If updating an existing repository, upload these files into the repository root. The old assets folder can remain; the site will use the new root-level photos.
