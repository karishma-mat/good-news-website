# Good News Christian A Cappella

Static rebuild of seven saved Squarespace pages.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the CONTENTS of this folder to its root, including index.html, style.css, script.js, and assets.
3. In Settings > Pages, choose Deploy from a branch, then main and /(root). Save.
4. Visit https://YOUR-USERNAME.github.io/REPOSITORY-NAME/.

## Before publishing
- The contact page uses goodnewsacap@gmail.com and @goodnewsacappella; the auditions page links to the supplied Google Form.
- Donation inquiries use kmathew@umich.edu. Email is an inquiry method, not a payment processor.
- Check names, biographies, auditions, and images for accuracy.
- The original footer had email@example.com and (555) 555-5555, so those placeholders were omitted.
- Some source pages referenced demo images; this build only downloads images under the group's Squarespace content ID.

Edit page text in each HTML file. Shared colors and layout are in style.css.
